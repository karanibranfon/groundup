# Sample Medical Images

This directory contains sample medical images for testing and demonstration.

## Files to add:

1. `knee_mri.dcm` or `knee_mri.jpg` - Sample knee MRI image
2. `chest_xray.dcm` or `chest_xray.jpg` - Sample chest X-ray image
3. `ct_scan.dcm` or `ct_scan.jpg` - Sample CT scan image

## Sources for public domain medical images:

- NIH Clinical Center: https://clinicalcenter.nih.gov/
- Open Access Series of Imaging Studies (OASIS): https://www.oasis-brains.org/
- Kaggle Medical Image Datasets: https://www.kaggle.com/datasets?tag=medical+image
- The Cancer Imaging Archive (TCIA): https://www.cancerimagingarchive.net/

## Supported formats:

- DICOM (.dcm)
- JPEG (.jpg, .jpeg)
- PNG (.png)
- TIFF (.tiff, .tif)

## Note:

Ensure you have the rights to use any images placed in this directory. 
For demonstration purposes, use synthetic or properly licensed sample images.
